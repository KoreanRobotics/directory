# KARA Directory

Browse members of the Korean-American Robotics Association by school, company, research area, and location.
Live at **https://koreanrobotics.github.io/directory/**.

Static site (no build step): `index.html`, `app.js`, `style.css`, and the data in `data/`.
Listing is **opt-in**: only people who submit the form and tick the consent box appear, and only with the fields they gave. Emails are never published.

## Files

| File | What it is |
|---|---|
| `data/people.json` | The directory. Generated by `scripts/sync.py`; don't edit by hand. |
| `data/places.csv` | Affiliation → map location. One row per institution or company office, with `|`-separated aliases. |
| `data/tags.json` | Research areas offered in the form and used as filters. |
| `scripts/sync.py` | Form responses CSV → `people.json`. Python 3 standard library only. |
| `tests/fixture.csv` | Fake responses for testing the script and the page. |

## Google Form

Create the form with these questions. The script matches columns by the start of each question's text, so keep these wordings (or edit `COLUMNS` at the top of `scripts/sync.py`).

Settings: **Collect email addresses** on (column "Email Address"; used only to keep each person's latest response). Allow response editing.

| Question | Type | Notes |
|---|---|---|
| Name (English) | Short answer, required | |
| Name (Korean) | Short answer | |
| Position | Multiple choice, required | Student / Postdoc / Faculty / Industry / Other |
| Title | Short answer | e.g. "Ph.D. Student", "Research Scientist" |
| Affiliation | Short answer, required | University or company |
| Lab / Department | Short answer | |
| City | Short answer | Used to place you on the map if the affiliation is new to us |
| Country | Short answer | |
| Research areas | Checkboxes + "Other" | Options: copy every line of `data/tags.json` exactly |
| Homepage | Short answer | |
| Google Scholar | Short answer | |
| LinkedIn | Short answer | |
| GitHub | Short answer | URL or username |
| CV | Short answer | A link to a CV you host (not an upload) |
| Action | Multiple choice, required | "Add or update my entry" / "Remove my entry" |
| Consent | Checkbox | One option: "I agree to have the information above listed publicly at koreanrobotics.github.io/directory." |

Put the form's share link in `FORM_URL` at the top of `app.js` to show the "Add yourself" button.

## Updating the directory

1. In the form's response Sheet: **File → Download → Comma-separated values**. Keep the file outside this repo and never use "Publish to web" (it would expose emails).
2. Preview, then write:
   ```
   python scripts/sync.py ~/Downloads/responses.csv --dry-run
   python scripts/sync.py ~/Downloads/responses.csv
   ```
   The report lists who was added / updated / removed, links that were dropped (bad URL or wrong site), research areas not in `tags.json`, and new places.
3. New affiliations are looked up on OpenStreetMap once and appended to `data/places.csv` with `needs_review=1`. Check the city and coordinates, add aliases if useful (e.g. `UMich|Michigan`), and clear the flag. Use `--no-geocode` to skip the lookup.
4. Commit `data/people.json` (and `data/places.csv` if it changed) and push. GitHub Pages updates in a minute or two.

**Removal requests by email:** ask the person to submit the form with "Remove my entry", or delete their row from the response Sheet, then re-run the sync.

**Same affiliation, different spellings:** add the spelling to that row's `aliases` in `places.csv` so people group under one map pin.

## Run locally

```
python -m http.server 8000
```
then open http://localhost:8000. To try the page with fake data: `python scripts/sync.py tests/fixture.csv --no-geocode` (don't commit the result).
